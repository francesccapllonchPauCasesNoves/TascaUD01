# Java Project — Unit 01 Task (TascaUD01) ☕

A **Java** application built with **Apache Maven** developed for **Didactic Unit 01 (UD01)**. This repository contains the practical implementation of core Java concepts, structured source code, and project configuration.

## ✨ Overview

- **Clean Maven Architecture:** Standard Java project layout managed through `pom.xml`.
- **Modular Codebase:** Organized packages and classes under `src/main/java` for maintainability and clarity.
- **IDE Ready:** Pre-configured with NetBeans run/debug actions (`nbactions.xml`) and compatible with IntelliJ IDEA and Eclipse.

## 🛠️ Tech Stack

- **Language:** Java
- **Build Tool:** Apache Maven (`pom.xml`)
- **IDE Configuration:** Apache NetBeans (`nbactions.xml`)
